# 🎬 Movie DB App (React + TypeScript)

 **React + TypeScript** and **TMDB API**.

##  Features
- Browse Popular / Top Rated / Upcoming Movies
- Search Movies
- Movie Details with Cast
- Watch Trailer
- Favorites (LocalStorage)
- Authentication UI (Mock)
- Responsive Netflix-style UI

## 🛠 Tech Stack
- React + TypeScript
- Webpack
- TMDB API
- CSS
